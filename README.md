# ⚔️ LevelUP+: Система прокачки уровня в Obsidian

Персональная система геймификации реальной жизни, построенная внутри Obsidian. Превращает выполнение ежедневных привычек и рутины в прокачку RPG-персонажа с начислением опыта, уровнями и накоплением золота.

---

## 📌 Основные механики

* **Характеристики героя:**
  * **STR (Сила):** физическая активность, тренировки, прогулки.
  * **INT (Интеллект):** учеба, чтение, концентрация, рабочие спринты.
  * **CHA (Харизма):** созвоны, нетворкинг, общение.
  * **WIS (Мудрость):** осознанность, медитация, контроль экранного времени.
* **Шкала опыта:** каждый уровень требует 500 XP.
* **Экономика (Gold):** каждые 10 XP суммарного опыта приносят 1 золотую монету для трат в магазине наград.

---

## 🛠️ Необходимые плагины

Для работы базовой сборки требуется установить сторонние плагины из каталога Obsidian (*Settings → Community plugins*):

1. **Dataview**
   * Обязательно активировать в настройках плагина:
     * `Enable JavaScript Queries`
     * `Enable Inline JavaScript Queries`
2. **Meta Bind**
   * Обеспечивает интерактивные переключатели `INPUT[toggle:...]` для квестов прямо в тексте.
